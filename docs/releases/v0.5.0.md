# v0.5.0 — session history + fresh-Mac install

## Session history (new)

Sessions no longer vanish when you quit. SessionHawk now keeps a local history:

- **History panel** (clock button in the footer): last 14 days, per-day rollups
  (sessions · agent working time · tokens) with per-session rows.
- Live sessions snapshot every 60s and get a final write when they end — a
  quit or crash loses at most a minute.
- Sessions now track time per state (working / waiting on you / idle), which
  powers the "agent time" numbers.
- **Private by design**: plain JSON under `~/.sessionhawk/history/`, one file
  per day, readable with `jq`, never sent anywhere. 90-day retention; delete
  the folder to wipe.

## Installs on a fresh Mac (no Homebrew needed)

- `install.sh` no longer hard-requires Homebrew or jq. Without jq you still
  get session states and needs-you notifications; token/limit stats switch on
  automatically once jq is installed.
- Hook setup falls back to python3 for the `~/.claude/settings.json` merge
  when jq is missing (same idempotent merge, same timestamped backup).
- Release download uses GitHub's stable redirect — no API parsing to break.

## Quality of life

- Session list orders needs-you-first: waiting → error → working → idle,
  stable within groups (no jitter on heartbeats).
- Gear button opens `~/.sessionhawk` with a generated `CONFIG.md` documenting
  every option; the empty state no longer points at a legacy script.
- bash users get the "working" state in the legacy shell hook (was zsh-only).
- Weekly limit gauges show reset countdowns; pace tracking warns when you're
  burning faster than the window ("12% over pace").

36 tests, CI green. macOS 14+, universal (Apple silicon + Intel).
